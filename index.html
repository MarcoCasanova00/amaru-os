AMARU OS / BUNKER ADVANCED

An experimental firmware image for the M‑VAVE FM‑1. This branch holds the alpha Web‑Assembly emulator. The real firmware image is in firmware/ on the main branch.

⚠️ Not released. Not flashed on hardware.

We have not validated this build on actual FM‑1 hardware. Do not flash it to a unit yet. Rollback to the stock image remains possible through the external installer / UBOOT recovery path, but no release guarantees apply in this alpha phase.

Try the WASM emulator

The browser emulator ships from firmware/web/emu/index.html and expects felucca.wasm next to it. It is not built on this branch — build it locally with Emscripten:

cd firmware
python3 tools/gen_bunker_library.py
EMU_PREVIEW=0 sh web/emu/build.sh

Then copy build/emu/{felucca.wasm,index.html,worklet.js,fonts/} here and push, or point GitHub Pages at /firmware/build/emu on the main branch after a manual build.
