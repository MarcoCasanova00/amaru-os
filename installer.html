AMARU OS — Web Installer Checkpoint

This page performs local-only identity / size / SHA-256 verification, then links to The Firmware Hub, whose WebMIDI installer is the only chip-level driver we treat as safe for AMARU packages.

No byte streamer is exposed locally. The firmware–flash path (Felucca's loader at 0xE0000) requires OTA sequencing; mistakes brick the device. If you are not comfortable flashing, use the hub's audited installer (Chrome / Edge, WebMIDI).
