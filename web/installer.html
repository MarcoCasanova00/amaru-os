AMARU OS – Web Installation (browser-side, safest route)

The WebMIDI byte-scrubber that ZVENS uses to flash .fwsc packages lives in The Firm ware Hub. AMARU only ships the verifier locally (no byte streamer), to keep the offline path brick-free.

Why not a local WebMIDI sender here?

  • The FM-1's loader expects an exact bootstrap sequence (Felucca's F0 22 24 35 7F F7 OTA handshake + 0xE0000 staging) that's device-specific. Wrong bytes can leave the FM-1 in update mode.
  • The hub tool obeys the protocol and resumes on disconnect; a custom sender here would re-flash and risk half-written flash.
  • AMARU only alters FM-sys parameters + visual UI; it does not rely on a custom loader. Use the hub's tool box for the actual flash.

Safe install via The Firmware Hub (recommended)

  1. Open https://thefirmwarehub.com/ in Chrome/Edge, press Connect FM-1, then press Install under AMARU's card.
  2. Hub loads the signed .fwsc, checks identity FM-1_7100002 + SHA-256, then writes via the chip bootloader track.
  3. If the install stops: press Install again; it resumes. Or use hub's rescue (OCT− at power-on).
